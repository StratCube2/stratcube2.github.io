# Modular
Modpack making tool with a bit too many features.
Thanks to:
- [Misode](https://misode.github.io/) for being de goat of datapacks

## Features
### Simple
- Modrinth search
- Filters from modrinth
- Exporting and Importing .mrpacks
- Adding mods from search aswell as from system
- Addons, just a collection of common mods in a modpack
- Comparability with modpack utility tools like YSNS and others (partial)
### Technical
- Adding recipes
- Reskinned items
- Tags, loot tables, Advancements
### Crazy shi
- Tweak world generation of terralith and tectonic (why(not))
- Make FTBQuests in the browser
- Scan mods for items from mods to be used in quests and recipes
